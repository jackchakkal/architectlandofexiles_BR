# Segurança

- A chave AES do jogo é necessária para gerar o PAK, mas **nunca** é aceita neste repositório: não a inclua em commits, issues, pull requests, capturas de tela ou releases. PRs que a contenham serão fechados e o histórico reescrito.
- O PAK distribuído contém apenas tabelas CSV de texto. Se você encontrar qualquer outro tipo de arquivo dentro de um pacote que alega ser desta tradução, ele não é oficial.
- Confira sempre o SHA-256 publicado na Release contra o arquivo baixado (`release.json` e `Get-FileHash` no PowerShell).
- Para reportar um problema de segurança, abra uma Issue sem incluir dados sensíveis, ou contate o mantenedor pelo GitHub.
